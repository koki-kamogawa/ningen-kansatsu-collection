# 人間観察コレクション

街で見かけた人を「あだ名・見た目・見たこと・予想」で登録すると、その人のアバターが空に浮かぶ島に降りてきて、性格どおりに暮らしはじめる箱庭アプリです。

- スマホのブラウザで開き、ホーム画面に追加するとアプリとして使えます
- 記録はすべて端末の中（ブラウザの保存領域）だけに保存され、どこにも送信されません
- サーバーもアカウントもありません。AIも使っていません
